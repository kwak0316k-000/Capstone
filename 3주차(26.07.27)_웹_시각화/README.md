# 3주차 과제: 캐릭터·대화·액션 웹 시각화

> 과제 원문 (2026.07.27)
> 숙제: 캐릭터 만들고, 대화하고, 액션하는 것 웹에 띄워서 시각화하기.
> - 액션은 1~2가지로 제한해도 됨

2주차에서 만든 캐릭터 3명(김소희·김재성·최수민)과 대화 시나리오를 그대로 가져와, 실제로 브라우저에서 열어볼 수 있는 웹페이지로 만들었다. 액션은 과제에서 허용한 대로 **방문한다 / 구매한다** 2가지로만 제한했다(원래 검색·찜 등도 있었지만 시각화를 명확하게 하려고 뺐다).

**바로 보기**: `index.html`을 브라우저로 열면 된다 (더블클릭하거나, `python -m http.server`로 로컬 서버를 띄워도 됨). GitHub Pages로 배포하면 링크 하나로 바로 공유할 수 있다.

---

## 1. 무엇을 만들었나

- **상단 "층별 안내판(Floor Guide)"**: 쇼핑몰 안내판처럼, 세 캐릭터를 각자 어울리는 층에 배치했다.
  - 4F(다이닝·리빙) — 김소희: 크림파스타·몬스테라 화분 취향
  - 1F(푸드코트·리뷰 분석) — 김재성: 돈카츠·라멘, 리뷰 집착
  - ?F(발길 닿는 대로) — 최수민: 정해진 층 없이 소품샵 위주로 배회
- **단톡방 대화**: 2주차에서 작성한 시나리오를 그대로 가져와, 실제 채팅앱처럼 말풍선 + 아바타로 표시
- **액션 배지**: 메시지 밑에 "📍 방문한다" / "🛍 구매한다" 배지를 붙여 어떤 행동인지 한눈에 보이게 함
- **재생 버튼**: 누르면 대화가 위에서부터 한 줄씩 순서대로 나타남 (페이지 로드 시 자동 재생도 됨)

## 2. 디자인 결정 근거

과제 자체가 정형화된 대시보드가 아니라 "동네에 생긴 쇼핑몰"이라는 구체적 소재를 다루고 있어서, 실제 쇼핑몰 안내판(층별 방문객 표시판)을 그대로 UI의 뼈대로 가져왔다. 색은 캐릭터 의상에서 그대로 따왔다 — 김소희의 세이지그린 후드티, 최수민의 브라운 톤 카디건/로퍼가 배지·강조색에 그대로 쓰였다. 흔한 AI 생성 페이지 톤(크림 배경 + 테라코타 강조색 조합)은 의도적으로 피하고, 짙은 차콜 배경에 세이지·머스터드·브라운을 포인트로 썼다.

## 3. 페르소나 반영 / 상호작용 (2주차 평가 요약)

2주차 README에 상세 평가가 있다 — 요약하면:
- 세 사람의 대사·행동 모두 실제 Nemotron 페르소나 필드(직업, 취미, 거주지)에서만 근거를 뽑았다 (지어낸 취향 없음)
- 김재성이 정보를 찾아 공유하고, 최수민이 그 정보를 받아 반응하는 등 **단순 병렬 반응이 아닌 실제 정보 교환**이 있다

## 4. 한계 및 다음에 할 것

- 대화 자체는 Claude가 세 명을 동시에 작성한 것이라, 진짜 독립된 3개의 에이전트가 실시간으로 주고받은 결과는 아니다 (2주차 `multi_agent_simulation.py`로 실제 API 호출을 통해 재현 가능)
- 액션을 2가지로 제한하다 보니 "검색한다"처럼 초기 반응 단계의 행동은 시각적으로 드러나지 않는다 — 필요하면 배지 색상만 추가해서 3번째 액션 타입으로 확장 가능

## 5. 재현 방법

```bash
# 그냥 브라우저로 열기
open index.html      # macOS
start index.html      # Windows

# 또는 로컬 서버로 (이미지 경로 문제 없이 안전하게 보려면 권장)
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages로 배포하려면 이 폴더를 레포에 올린 뒤 Settings → Pages에서 해당 브랜치/폴더를 지정하면 된다.
